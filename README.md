## Para actualizar el sitio

Todo está en `index.html` y los certificados en `assets/certificados/`. Los textos existen en español y en inglés, al final de ese archivo: si cambia una frase, conviene tocarla en los dos idiomas.

La página se publica sola con GitHub Pages. Al guardar cambios en la rama `main`, [valennsosa.github.io](https://valennsosa.github.io/) se actualiza en unos minutos.
